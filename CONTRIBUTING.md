# Contributing to PipesHub

Thank you for contributing! This guide applies to every repository in the [pipeshub-ai](https://github.com/pipeshub-ai) organization that has no `CONTRIBUTING.md` of its own. Where a repository has its own guide, follow that one.

Questions: [Discord](https://discord.com/invite/K5RskzJBm2) or [GitHub Discussions](https://github.com/pipeshub-ai/pipeshub-ai/discussions).

## Pull requests

1. Fork the repository and create a branch for your change.
2. Make your change, and test it where the repository has tests.
3. Open a pull request with a clear description of what changed and why. Reference any related issues.

## Contributor License Agreement

Before we can merge your first pull request, you need to sign our [Contributor License Agreement](https://github.com/pipeshub-ai/pipeshub-ai/blob/main/CLA.md) (CLA). You keep the copyright to your work; the CLA gives PipesHub a license to use and distribute it. One signature covers all PipesHub repositories.

The CLA Assistant bot comments on your pull request with a link; follow it, sign in with GitHub and select **I agree**. You only sign once.

If the `license/cla` check is still failing after you signed:

- Select **recheck** in the bot's comment; that re-runs the check.
- Make sure the email in your commits is linked to your GitHub account. The [main repository's guide](https://github.com/pipeshub-ai/pipeshub-ai/blob/main/CONTRIBUTING.md#contributor-license-agreement) shows how to fix commits made with an unlinked email.
